# Editor Asternal independiente

- [ ] La página independiente carga directamente el editor antiguo Asternal, sin portada, paneles ni navegación del portal original.
- [ ] Se reutilizan los componentes, estilos, recursos y lógica existentes del repositorio.
- [ ] Se conservan la gestión y edición de escenas, las herramientas de interfaz y pintura, la animación, los scripts y la vista previa integrada.
- [ ] Las rutas, dependencias y configuración de arranque permiten que el editor funcione de forma autónoma fuera del portal.
- [ ] La aplicación compila y queda disponible en Preview.
